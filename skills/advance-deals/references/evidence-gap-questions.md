# Evidence-gap questions

Questions are generated from what is missing, phrased for this account, and ordered by how much a good answer changes the forecast. Generic discovery lists are not used.

## Per missing element

| Missing | Question pattern | Why it matters |
|---|---|---|
| Business problem in their words | "When <situation from a signal or a prior statement> happens, what does it cost you in a normal week?" | anchors value in their arithmetic |
| Desired outcome | "If this works, what will be true in <timeline> that is not true today?" | defines success before we do |
| Timeline | "What is driving <date>? What happens if it slips a quarter?" | separates a wish from a deadline |
| Decision process | "Who else needs to be comfortable with this, and what do they need to see?" | reveals the paper and people path |
| Economic buyer | "Whose budget does this come from, and have they seen the numbers yet?" | confirms funding and access |
| Champion | "If you had to make the case internally in one slide, what would be on it?" | tests whether they will sell for you |
| Success metrics | "How will you measure this after go-live, and what is the number today?" | creates the baseline |
| Alternatives | "What are you comparing this with, including doing nothing?" | surfaces competition and inertia |
| Paper process | "What does procurement need from us, and how long did the last vendor take?" | prevents a surprise at the end |
| Commitments | "What would you want to have in hand by our next call?" | turns a chat into a mutual plan |

## Ordering

1. Elements that block the forecast (buyer, timeline, decision process).
2. Elements that shape the proposal (problem, outcome, metrics).
3. Elements that prepare the close (alternatives, paper, commitments).

Ask at most three in one meeting. The rest go into the follow-up or the next prep.

## Phrasing rules

- Reference something they said or something observable. Never open with the pattern verbatim.
- One question per sentence.
- No leading questions that contain our claim.
- Write the expected answer next to each question in the prep file so the seller notices when the real answer differs.
