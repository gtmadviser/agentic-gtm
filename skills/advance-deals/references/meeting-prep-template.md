# Meeting preparation

Write to `meetings/<YYYY-MM-DD>-<slug>-prep.md`. Redacted: roles instead of names where possible, no emails, no phone numbers, no transcript text. Depth follows the mode: a quick check deserves a paragraph, a decisive meeting deserves the full page.

```markdown
# <Company> · <meeting purpose> · <YYYY-MM-DD>
Mode: <IC | leader> · Prepared: <date> · Sources checked: <crm, meetings, email, chat> · Unavailable: <list or none>

## Opportunity
Stage: <stage> (entered <date>) · Amount: <amount> · Close: <date> (moved <n> times) · Owner: <role>
Last activity: <date> (<n> days ago) · Next step on record: <text or none>

## What the customer said
| Element | Statement | Source | Date |
|---|---|---|---|
| Business problem | "<paraphrase or quote>" | [customer] recording | <date> |
| Desired outcome | | | |
| Timeline | | | |
| Decision process | | | |
| Economic buyer | | | |
| Champion | | | |
| Success metrics | | | |
| Alternatives named | | | |
| Commitments they made | | | |

## What we think it means
| Element | Interpretation | Basis |
|---|---|---|
| | inferred: <reasoning> | [seller] note <date> |

## Not found in any source
- <element>: checked <sources>

## Evidence-gap questions for this meeting
1. <question phrased for this account, closes element X>
2. ...
3. ...

## Risks
- <rule that fired>: <detail>

## Our commitments outstanding
- <what we promised, when, status>

## Suggested agenda (15 minutes)
1. Confirm <element> in their words (3 min)
2. Close gaps 1 to 3 (7 min)
3. Agree mutual next steps with dates (5 min)
```

## Rules

- Elements with no source say `not found`. They are the agenda.
- The interpretation table never feeds the follow-up draft directly.
- Internal chat assessments are summarized in the risks section as `[internal]`, never quoted.
