# Review Outreach

Read the preregistered experiment and its original decision rule.

1. Run `gtm --json sync campaigns`, then `gtm --json review outreach`.
2. Verify the time window, denominator, duplicate-event handling, provider status definitions, and missing data before interpretation.
3. Report delivery, positive/qualified replies, meetings, opportunities, and safeguards using the experiment's denominator.
4. Compare results to the unchanged continue/change/stop rule. Treat unexpected findings as new hypotheses.
5. Update the experiment, evidence register, and learning log with result, confidence, limitations, and human decision.

Do not activate campaigns, expand volume, or rewrite the original rule without a new approved experiment version.
